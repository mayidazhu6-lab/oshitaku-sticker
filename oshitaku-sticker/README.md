# 🌈 あさのおしたくシールちょう v0.1

3歳くらいの子どもが iPad 横向きで使える、シンプルなおしたくシール帳です。

## できること
- 「おきがえ」「あさごはん」「といれ」をタップするとランダムなシールが登場
- シールを貼るとキラキラ演出、3つ揃うとお祝い演出
- 同じ項目を誤タップしてもシールが消えない
- 当日の達成状況だけブラウザの `localStorage` に保存
- 日付が変わったら自動リセット（アプリを開きっぱなしでも確認）
- 親用のリセットボタンは確認ダイアログ付き
- アカウント・サーバー・外部通信・画像アップロードなし

## PCで起動
Node.js 20.19+ または 22.12+ を推奨。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## GitHub Pages 公開
1. GitHubで **新しい公開リポジトリ**（例 `oshitaku-sticker`）を作成します。
2. このフォルダの**中身**をリポジトリの `main` ブランチにpushします（ZIPそのものではなく展開したファイル）。
3. GitHubの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更します。
4. **Actions** タブで `Deploy to GitHub Pages` が成功するまで待ちます。
5. `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` にアクセスします。

`vite.config.js` はGitHub Actionsの `GITHUB_REPOSITORY` から公開パスを自動設定します。

## iPad
Safariで公開URLを開き、共有メニューから「ホーム画面に追加」を選びます。最初は横向きで使ってください。

## 注意
- GitHub Pagesは**身内限定公開ではありません**。URLを知らない人もアクセスできます。名前・写真・個人情報は入れないでください。
- 進捗は**iPadのそのブラウザ内だけ**に保存されます。別端末と同期しません。ブラウザデータ削除やプライベートブラウズで消えることがあります。
- 日付は端末のローカル時刻に基づきます。
- GitHub PagesはMVPの無料公開用。将来の有料サービス運営には別のホスティングを検討してください。
