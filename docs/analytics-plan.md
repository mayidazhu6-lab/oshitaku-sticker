# アクセス解析の導入準備

このブランチでは、Cloudflare Web Analytics を利用してアプリの閲覧状況を把握する準備をします。

## 方針
- GitHub Pages のまま運用し、公開中のアプリに影響させない
- 子どもの名前、シールの達成状況、localStorage の値は送信しない
- 初期段階はページ閲覧数と訪問者数の目安だけを確認する
- 計測導入後はプライバシー説明を更新する

## 導入前に必要な作業
1. Cloudflare Web Analytics で対象サイトを登録する
2. 表示される **サイト固有の計測トークン** を取得する（APIキーやパスワードではない）
3. トークンを Vite の公開環境変数 `VITE_CF_WEB_ANALYTICS_TOKEN` としてビルド時に渡す
4. `index.html` から Cloudflare の公式 beacon スクリプトを読み込む。トークンが未設定の場合は読み込まない
5. プライバシー説明に Cloudflare によるアクセス解析を記載し、公開前に挙動を確認する

> 注意: 計測は導入以降のアクセスのみ。過去の訪問数は復元できません。IPアドレス等の通信メタデータの取扱いも含め、Cloudflare の最新の仕様とプライバシー情報を公開前に確認してください。
